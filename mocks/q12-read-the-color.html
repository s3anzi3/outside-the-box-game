Q.12 · Read the Color · faithful mock in the current theme

Fully playable. A Stroop test: the prompt asks for the word printed in GREEN ink. Exactly one word is inked green, and it is not the word that spells GREEN. That word (the trap) is inked yellow; the green ink is on PURPLE. Clicking anything but the green-inked word slams INCORRECT and costs a heart. Theme restyle versus the real build: the six ink colors are muted fountain-pen versions of the original bright arcade hues so they sit on the ivory paper, but each stays unmistakably nameable. A faint hover wash marks the word cells as clickable.
